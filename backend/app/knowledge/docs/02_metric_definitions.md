# 指标与业务口径

## 高价值流失召回

高流失定义为 churn_score >= 0.70；高客单价定义为最近 180 天已完成订单的平均实付金额 >= 500 元；必须具有营销授权，且最近 7 天触达次数小于 2。主指标为触达后 30 天复购率。未明确“提升 5%”时，默认解释为相对提升 5%，并向使用者披露该假设。

## 618 连续购买

时间窗口为 2026-06-15 至 2026-06-18，采用左闭右开时间边界。按 user_id + 日期汇总；当天平均实付金额 > 500 元视为有效购买日。使用日期减 row_number 的 Gap-and-Island 方法识别至少连续 3 天的用户。

## 实验指标

主指标必须与业务目标一致。护栏指标至少包括退订率、投诉率、优惠成本和重复触达率。A/B/C 默认分流为 34%/33%/33%，结果按 user_id 的稳定哈希分桶。
