# Agno 工作流与人工审核

## Agent 与 Workflow 分工
Agent 负责目标解析、SQL 生成、工具选择、实验设计和文案评审；Workflow 固定执行顺序、条件分支、重试上限和暂停点。该分工避免模型自行跳过关键安全步骤。

## 持久化人工审核
当客群超过五万人时，工作流写入 SQLite 并进入 PAUSED_REVIEW。批准后读取原有业务简报、SQL 与护栏结果继续执行；驳回后进入不可继续的 REJECTED 状态。刷新页面不会丢失审批状态。

## 事件审计
SSE 只输出任务依据、工具调用、验证结果、修复原因和决策摘要，不展示模型隐藏思维链。每次事件具有运行编号、阶段、状态和时间戳。
